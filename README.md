# 📊 Stock Portfolio Tracker

A Python-based project to track stock investments and calculate total portfolio value with percentage breakdown.

---

## 🚀 Features

* View stock prices
* Add multiple stocks
* Calculate investment value
* Show percentage allocation
* Input validation
* Export data to CSV

---

## 🛠️ Tech Used

* Python
* OOP
* CSV module

---

## ▶️ Run Project

```bash
python portfolio.py
```

---

## 📁 Output

* Generates `portfolio.csv` with stock details
